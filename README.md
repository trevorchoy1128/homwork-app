# 交功課紀錄 App（iPhone 網頁版）

幫老師在手機上快速記錄誰交了功課、誰未交，一鍵用 WhatsApp 追收，並把紀錄匯出至 Excel 或同步到 Google Sheet。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | App 主程式（單一檔案，含全部畫面及邏輯） |
| `manifest.json`、`sw.js`、`icon.png` | 讓 App 可「加入主畫面」、離線開啟 |
| `Code.gs` | 貼到 Google Apps Script，作為 Google Sheet 同步端點 |

## 一、放上網（三選一）

App 是純靜態網頁，放到任何可用 https 的空間即可：

1. **Netlify Drop**（最簡單）：到 https://app.netlify.com/drop ，把整個資料夾拖進去，即獲得網址。
2. **GitHub Pages**：建立 repo，上載這些檔案，Settings → Pages → 選 main branch。
3. **學校網頁空間**：把檔案放到任何 https 資料夾。

> 用 `file://` 直接開啟也能運作，但「加入主畫面」及離線功能需要 https。

## 二、加到 iPhone 主畫面

1. 用 Safari 開啟網址
2. 按底部「分享」→「加入主畫面」
3. 之後從主畫面開啟，會像原生 App 一樣全螢幕

## 三、日常使用

1. **學生**頁：按「＋」逐個新增，或按「批量貼上匯入」，直接從 Excel 複製整班名單貼上（欄位順序不限，會自動辨認班別／學號／姓名／電話）。
   - 每位學生可填多個**科目**（例：中文、數學）。學生頁頂部可按班別及科目篩選，亦有搜尋欄可輸入姓名／電話／科目。
   - 匯入時（Excel、貼上、Google Sheet）若有「科目」欄會自動讀取，多個科目以逗號、頓號或斜線分隔；沒有的話可在匯入時填一個預設科目套用到全部。
   - 每位學生可填**多個電話**（例如本人、家長），最上面的是預設；追收頁可用下拉選單即時選擇傳給哪一個號碼。Excel 名單可有多個電話欄（如「學生電話」「家長電話」），或用「其他電話」欄填 `家長:98765432、本人:95556666`。
   - 右上「選取」進入批量模式，可一次過刪除、改班別、加減科目；「班別管理」可為班別改名或刪除整班。
2. **功課**頁：按「＋」新增功課，可選「科目」，這樣只會列出修讀該科的學生。預設「全部已交」，之後只需點一下未交的同學把他們改成「未交」。
3. 功課詳情頁按 **「一鍵 WhatsApp 追收」**：
   - 「傳送給下一位」每按一次會開啟 WhatsApp 並自動填好訊息給下一位未交的同學，按傳送後返回 App 再按一次。
   - 「傳未交名單至群組」會把整份未交名單一次過發到你選擇的班級群組。
   - 訊息範本可在「設定」修改，可用變數 `{姓名} {班別} {學號} {功課} {日期} {老師}`。
4. **匯出**頁：匯出 Excel／CSV，或同步至 Google Sheet；亦可做 JSON 備份。

**日常快捷功能**

- **輸入學號標記未交**：新增功課時或在功課頁輸入「3 7 12」，這些學號標為未交，其餘自動已交。
- **未交總覽**：功課頁頂部的「未交總覽」列出所有班別今日（或全部）未交學生，可在此逐一追收。
- **一次派多班**：新增功課時班別可多選。
- **收簿日**：設了收簿日的功課未到期前顯示「尚未收」，不計入未交總覽，也不會誤傳追收訊息。
- **補交**：已過日期或已提醒的未交學生改為已交時自動記為「遲交」並記錄補交日期；追收頁有「已補交」按鈕。
- **多次提醒與家長升級**：追收頁分「未提醒」「已提醒仍未交」；第二次起自動用較嚴厲範本；提醒過的學生可一鍵傳訊給備註為「家長」的電話。三個範本都可在設定修改。
- **名單出圖**：追收頁「名單出圖」把未交名單生成圖片，方便貼到班群。
- **學生個人頁**：學生頁點學生可見累計未交／遲交、欠交率、全部功課歷史及備註；名單上顯示「未交 N」，達門檻（預設 3 次，可在設定改）會標紅。
- **今日／本週篩選**：功課頁可只看今日或本週的功課。

> **WhatsApp 限制**：WhatsApp 不允許網頁在背後自動群發訊息（那是付費的 WhatsApp Business API），所以每位同學仍需在 WhatsApp 按一次「傳送」。App 已把訊息全部填好，並記錄「已提醒」時間，實際只需每人一按。

## 四、Google Sheet 同步設定

1. 開一個新的 Google Sheet
2. 選單「擴充功能」→「Apps Script」
3. 刪除預設內容，貼上 `Code.gs` 全部內容，儲存
4. 右上「部署」→「新增部署作業」→ 類型「網頁應用程式」
   - 執行身份：**我**
   - 誰可以存取：**任何人**
5. 按「部署」，完成 Google 授權（會有「未經驗證」警告，按「進階」→「前往…（不安全）」即可，因為是你自己的程式）
6. 複製「網頁應用程式網址」（以 `/exec` 結尾），貼到 App 的「設定」→「Apps Script 網頁應用程式網址」
7. 回到「匯出」頁按「立即同步」，Google Sheet 會出現三種工作表：
   - `功課紀錄`：每項功課每位學生一行（日期、班別、功課、學號、姓名、電話、狀態、提醒時間）
   - `總覽-班別`：每班一張，學生 × 功課 的 ✓／✗／遲 矩陣，另有未交及遲交次數
   - `學生名單`：可在電腦上直接在此表輸入整班名單，再在 App「學生」頁按「從 Google Sheet 匯入」

「設定」內的**自動同步**預設開啟，每次修改紀錄後約 4 秒自動上傳。

### 多部裝置共用

同步時 App 會把全部資料（學生、科目、功課、紀錄）存到 Google Sheet 內一張隱藏工作表 `_app_data`，所以：

1. 每部裝置（iPhone、iPad、電腦瀏覽器）都貼上**同一條** Apps Script 網址，並保持「自動同步」開啟。
2. 開啟 App 或從背景切回來時，會自動檢查雲端並載入較新的資料；修改後約 4 秒自動上傳。
3. 「匯出」頁的「從雲端載入最新資料」可隨時手動檢查。
4. 若兩部裝置都在未同步的情況下改過資料，上傳時會提示你選擇「以雲端取代本機」或「保留本機並覆蓋雲端」。

> 這是先後同步而非即時共同編輯：兩人同一時間在不同手機改同一份資料，後上傳的會覆蓋先上傳的。一位老師多部裝置使用沒有問題；多位老師請各自用自己的 Google Sheet。
>
> 請勿手動修改 `_app_data` 工作表（預設已隱藏）。

### 定時電郵摘要與自動備份（選用）

1. 在 Apps Script 編輯器上方的函數下拉選「setupTriggers」→ 按「執行」→ 授權 Gmail 及 Drive。
2. 之後會自動：每朝 8 時電郵當日未交名單給你；每週五 16 時電郵各班欠交統計（可在 Code.gs 頂部 `WEEKLY_EMAILS` 填班主任電郵）；每日凌晨 2 時把資料備份到 Google Drive「交功課紀錄備份」資料夾，保留 30 天。
3. 時間及收件人可在 Code.gs 頂部修改，改後再執行一次 setupTriggers。執行「deleteTriggers」可全部停用。

### 分享給其他老師（各自一份 Google Sheet）

1. 把 App 網址給同事，App 本身大家共用，資料互不相通。
2. 為省去同事貼程式碼的步驟，可做一個**範本 Sheet**：你自己新建一個 Google Sheet，貼好 Code.gs 但**不要**輸入任何資料，把它以「知道連結的使用者可檢視」分享給同事。
3. 同事開啟範本 → 檔案 → 建立副本。副本會連程式碼一併複製，之後只需按 App「設定」頁的「首次設定精靈」第 ②③ 步部署及貼網址即可。
4. 每位同事的 Apps Script 網址只給自己的裝置用，不要互相交換。

## 五、用 Excel 作為同步檔案（不用 Google Sheet 亦可）

1. 在電腦準備一個 Excel，第一行為標題：`班別`、`學號`、`姓名`、`電話`（中英文標題皆可辨認，欄位次序不限；也可在 App「學生」頁按「下載 Excel 名單範本」取得範本）。
2. 把 Excel 放在 OneDrive 或 iCloud Drive，iPhone 的「檔案」App 便能看到。
3. App「學生」頁 →「從 Excel 匯入」→ 在「檔案」選該 Excel → 選工作表 → 匯入。勾選「連結此 Excel」後，App 會記住檔內其他工作表。
4. 之後在「匯出」頁按「匯出 Excel」，會以**相同檔名**輸出，內含你原本的工作表加上 `功課紀錄`、`總覽-班別`、`學生名單`。在分享面板選「儲存到檔案」→ 同一資料夾 →「取代」，OneDrive／iCloud 便會自動同步回電腦。
5. 電話有更新時，在 Excel 改好後再「從 Excel 匯入」一次即可（以班別＋姓名配對更新）。

> 限制：iPhone 網頁不能在背後直接改寫手機上的檔案，所以「寫回 Excel」是由你在分享面板按一下「取代」完成。另外輸出的 Excel 會保留原有工作表的內容，但不會保留顏色、字型等格式。

## 六、注意事項

- 資料儲存在手機瀏覽器內（localStorage），刪除 Safari 網站資料會清空，請定期同步或匯出備份。
- 電話號碼 8 位或以下會自動加上「設定」內的區號（預設 852）。
- 若按追收後 WhatsApp 沒有開啟，可在「設定」開啟「以 wa.me 網頁連結開啟」。
- 「誰可以存取：任何人」代表知道網址的人都可以寫入該 Google Sheet，網址請勿公開。
